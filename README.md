## 安装

```bash
# Docker
docker pull sexyfeifan/nodus:0.0.3
```

或前往 [GitHub Releases](https://github.com/sexyfeifan/Nodus/releases/latest) 下载各平台二进制包，详见 [安装文档](https://github.com/sexyfeifan/Nodus/tree/main/docs/deploy)。
